# 🎯 Focus Tracker

Приложение для управления задачами, фокус-сессиями и временем концентрации  
с жёстким режимом фокуса.

---

## 🚀 Основные возможности

### 👤 Пользователь и профиль
- Регистрация и авторизация
- JWT-аутентификация
- Профиль пользователя

### 📚 Предметы и области
- Создание предметов (учёба, работа, проекты)
- Группировка задач по предметам

### ✅ Задачи
- Создание задач с привязкой к предмету
- Оценка времени выполнения
- Отслеживание статуса задач

### ⏱ Фокус-сессии
- Таймер концентрации
- Пауза / продолжение / сброс
- Учёт фактически затраченного времени

### 🔒 Жёсткий режим фокуса
- При выходе со вкладки фокус-сессия автоматически завершается

### 📊 Статистика
- Общее время в фокусе
- Статистика по задачам и предметам
- Аналитика продуктивности

---

## 🧠 Архитектура

Frontend и Backend разделены, взаимодействие через REST API.

---

## 🛠 Backend

**Стек:**
- C#
